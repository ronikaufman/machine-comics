Machine Comics by Roni Kaufman

Zoom in, zoom out.

Machine Comics is an experiment in generative storytelling, an abstract graphic novel drawn by an algorithm. Paying homage to pop art and classic comic book aesthetics, saturated colors and halftone dots create unexpected patterns and vibrant textures in each unique page.

The project was originally sold on Art Blocks in 2022. Its code was written in p5.js.
